All-Russian 2007

\begin{problem}[https://artofproblemsolving.com/community/u1159306h147176p39662015]
    Do there exist non-zero reals $a$, $b$, $c$ such that, for any $n>3$, there exists a polynomial $P_{n}(x) = x^{n}+\dots+a x^{2}+bx+c$, which has exactly $n$ (not necessary distinct) integral roots?
\end{problem}
\begin{proof}
    Let us first show the following result,

\begin{lemma}
    There are no $n$ and $m$ such that $P_n \mid P_m$ and the ratio has zero $x$ and $x^2$ terms.
\end{lemma}
\begin{proof}
    Since both $P_n$ and $P_m$ have the same last coefficients, it must be that,
    \[
    (\ldots + ax^2 + bx + c) \cdot (\ldots + dx^2 + ex + f) = \ldots + ax^2 + bx + c
    \]
    trivially it means that $f = 1$, $b = ce + bf = ce + b$ and $a = af + be + cd = a + be + cd$, however this implies that $d = e = 0$!
\end{proof}

    Observe, that by Vieta (looking at $c$) it must be that $P_n(x) = (x - 1)^{\alpha_n} (x + 1)^{\beta_n} Q_n(x)$, where $\deg Q$ has bounded degree. Observe, that thus by Veita (for $c$) there exists some $Q$ such that there are infinitely many $k$ such that $Q_k = Q$.

    Let us look for all of those \textit{same class} $P_n$ (where the \textit{class} is $Q_n$) and look at the pairs $(\alpha_n, \beta_n)$. Let us assume that $(\alpha_n, \beta_n) < (\alpha_m, \beta_m)$ (less in both coordinates), then this will imply that, that $P_n \mid P_m$ and the ratio is of the form $(x - 1)^{\alpha} (x + 1)^{\beta}$.

    \begin{lemma}
        The $x$ and $x^2$ term of $(x - 1)^{\alpha} (x + 1)^{\beta}$ cannot both be zero.
    \end{lemma}
    \begin{proof}
        Indeed, by looking at the $x$ term we conclude that $\alpha = \beta$ (if the coefficient is zero) and the coefficient in front of $x^2$ up to sign is equal to $\binom{\alpha}{2} + \binom{\beta}{2} - \alpha \beta$ which cannot be zero if $\alpha = \beta$!
    \end{proof}

    Thus, if $(\alpha_n, \beta_n) < (\alpha_m, \beta_m)$ we obtain a contradiction. Let us now plot on the $\mathbb{Z}^2_{\geq 0}$ the points, then all we need to show is the following result.

    \begin{lemma}[Infinite Chomp]
        There is no infinite sequence of points $(x, y)$ such that no two are \textbf{contained} (so both coordinates less than the other) in each other.
    \end{lemma}
    \begin{center}
    \begin{asy}
settings.outformat = "pdf";
size(8cm);

int XMAX = 7;
int YMAX = 7;

// Function to shade the infinite rectangle (ideal) in grey
void shadeIdeal(int x, int y) {
    // Extend slightly past the max grid for the infinite effect
    real extX = XMAX + 0.5;
    real extY = YMAX + 0.5;
    
    path rect = (x,y) -- (extX, y) -- (extX, extY) -- (x, extY) -- cycle;
    // Using a light grey with opacity so overlaps become slightly darker
    fill(rect, gray(0.7) + opacity(0.3));
    
    // Draw dashed borders to indicate it extends to infinity
    draw((x,y) -- (extX, y), black + dashed + linewidth(1));
    draw((x,y) -- (x, extY), black + dashed + linewidth(1));
}

// Draw the shaded regions first so they sit in the background
shadeIdeal(1, 5);
shadeIdeal(3, 3);
shadeIdeal(5, 1);

// Draw grid lines in very light grey
for(int i=1; i<=XMAX; ++i) draw((i,0)--(i,YMAX+0.5), gray(0.9));
for(int j=1; j<=YMAX; ++j) draw((0,j)--(XMAX+0.5,j), gray(0.9));

// Draw axes in black
draw((0,0)--(XMAX+0.8,0), black, Arrow(6));
draw((0,0)--(0,YMAX+0.8), black, Arrow(6));

// Label the X-axis with x monomials
label("$1$", (0, -0.5));
for(int i=1; i<=XMAX; ++i) {
    if (i == 1) label("$x$", (i, -0.5));
    else label("$x^{" + (string)i + "}$", (i, -0.5));
}

// Label the Y-axis with y monomials
for(int j=1; j<=YMAX; ++j) {
    if (j == 1) label("$y$", (-0.5, j));
    else label("$y^{" + (string)j + "}$", (-0.5, j));
}

// Plot the generating points as black dots and label their monomials
dot((1,5), black + linewidth(4));
label("$xy^5$", (1,5), SW);

dot((3,3), black + linewidth(4));
label("$x^3y^3$", (3,3), SW);

dot((5,1), black + linewidth(4));
label("$x^5y$", (5,1), SW);

    \end{asy}
    \end{center}
    \begin{proof}
        One can reinterpret the problem as drawing infinite rectangles to the up-right of a point and one is required to show that some two rectangles are contained in each other. Let us associate to each point the monomial $x^{a} y^b$ where $a, b$ are the coordinates of the point.

        The infinite rectangle may be interpreted as the ideal generated by the monomial in the ring $\mathbb{Z}[x, y]$, then by iteratively putting points on the plane one is creating larger and larger ideals, thus creating an infinite chain,
        \[
        I_0 \subseteq I_1 \subseteq I_2 \subseteq \ldots
        \]
        however by Hilbert's Basis theorem we know that $\mathbb{Z}[x, y]$ is Noetherian (since $\mathbb{Z}$ is Noetherian), thus by definition this sequence must stabilize, which will imply that one point is contained in another!
    \end{proof}
    This will give us the desired pair $n, m$ with $(\alpha_n, \beta_n) < (\alpha_m, \beta_m)$ and thus we are done!

    Consequently, no desired triple $(a, b, c)$ exists!
\end{proof}
